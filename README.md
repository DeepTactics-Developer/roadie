# ROADIE

운전을 이야기로 만드는 반려차 드라이브 앱. 기분과 시간만 말하면 순환 코스를 짜고, 길 위의 장면에 맞춰 음악을 재배열합니다.

Pleos Connect 차량 환경용 앱입니다. 반려차 "로디"에게 "40분, 바다 느낌, 신호 적은 길"처럼 말하면 지금 위치에서 출발해 같은 곳으로 돌아오는 코스를 만들어 내비에 넘깁니다. 달리는 동안 터널 출구, 바다가 열리는 지점, 고갯마루 같은 장면에 도착하는 순간 음악이 터지고, 갈림길에서는 어느 길로 갈지 묻습니다. 도착하면 그날 달린 도로의 성격을 테이스팅 노트로 정리합니다.

## 주요 기능

### 말로 짜는 순환 코스
- 홈에서 마이크를 누르고 시간과 기분을 말합니다. 화면의 예시 문장을 눌러도 됩니다.
- 시간(40분, 한 시간 반), 분위기(바다, 호숫가, 고갯길, 시내), 조건(신호 적은 길, 굽이진 길, 한적한 길)을 규칙으로 알아듣습니다.
- 도로를 조각으로 나눈 데이터(아래 "도로 데이터" 참고)에서, **지금 위치**를 출발해 같은 곳을 두 번 지나지 않고 돌아오는 길을 모두 찾아 점수를 매깁니다. 시간이 얼마나 맞는지, 원하는 분위기 구간이 얼마나 긴지, 신호와 굽이 수, 지금까지의 취향을 반영합니다.
- 결과는 지도 그림, 예상 시간, 거리, 신호 수, 바다/호숫가/산길 비율, 장면 목록, 갈림길 위치로 보여 줍니다. "다른 코스"를 누르면 앞서 나온 코스와 길이 60% 이상 겹치는 후보(같은 길을 거꾸로 도는 것 포함)는 건너뛰고 다음 후보를 보여 줍니다.
- 갈림길이 있는 코스에는 가산점을 주고, 갈림길 질문이 장면 대사나 드롭과 겹치지 않는 자리(장면 앞 80초, 뒤 40초 밖)에 둡니다.
- 출발지는 항상 지금 위치입니다(NaviHelper의 현재 위치). 지금 위치와 가장 가까운 도로 지점 사이, 마지막 지점과 지금 위치 사이는 지도 데이터가 없어서 직선거리를 1.3배 한 값으로 추정한 "연결 구간"으로 잇습니다. 연결 구간에는 장면이 없고, 화면에서는 점선과 "지도 분석 없음"으로 표시하며 점수도 깎습니다.
- 출발하면 NaviHelper로 경유지 2곳을 넣어 경로를 요청합니다. 연결 구간은 내비가 따로 안내하지 않을 수 있습니다.

### 도로 데이터
- 지역별 JSON 파일(`app/src/main/assets/roads/`)로 나눠 두고, `index.json`의 범위(bbox)로 지금 위치를 덮는 지역만 읽습니다. 지금은 수도권(서울·경기·인천, 지점 62곳, 연결 158개)과 강릉(16곳, 28개)이 있고, 지역 파일을 추가하면 전국으로 늘릴 수 있는 구조입니다. 덮는 지역이 없는 곳에서는 코스를 만들지 못한다고 알려 줍니다.
- 도로 조각의 거리, 평균 속도, 신호 수, 굽이 수, 오르막, 터널, 다리, 해안 구간, 호숫가, 강변, 고개 이름과 **장면 위치는 실제 지도 데이터로 잰 값**입니다. `tools/osm_extract.py`가 OpenStreetMap 데이터(Geofabrik)에서 지역별 신호등, 터널, 다리, 해안선, 호수, 강, 고개와 봉우리 이름을 뽑고, `tools/build_roads.py`가 조각마다 재서 JSON으로 만듭니다. 앱은 인터넷 없이 이 값으로 코스를 짭니다.
  - 경로와 거리, 시간, 도로 이름: OSRM 공개 서버(OpenStreetMap 도로망)
  - 고도: AWS Terrarium 타일(SRTM 기반)
- 사람이 정한 것은 지역 파일(`tools/regions/*.json`)의 지점 목록과, 어떤 지점끼리 길로 이을지(가까운 지점끼리 자동으로 잇거나 직접 지정)입니다. 장면 대사 문장과 판정 기준(터널 250m 이상, 해안 600m 이상 붙어 달리는 구간, 오르막 80m 이상 솟은 곳 등)도 제가 정했습니다.
- 굽이는 경로 모양이 150m 안에 55도 넘게 꺾이는 횟수, 신호는 경로에서 30m 안의 신호등(60m 안은 하나로), 해안은 해안선에서 250m 안, 호숫가는 호수 경계에서 150m 안으로 셉니다.
- 지도 데이터 © OpenStreetMap contributors (ODbL), 고도 AWS Terrarium(SRTM 등).

### 내비와 함께 쓰기
- 출발하면 NaviHelper로 경로를 요청하고, 내비 앱이 화면을 차지합니다. 우리 앱은 화면에 떠 있지 않아도 **주행 서비스(포그라운드 서비스)**로 계속 돌아갑니다. 음악, 반려차 음성, 갈림길 질문과 음성 인식이 모두 내비가 앞에 있는 상태에서 이어집니다.
- 화면은 출발 전(코스 짜기)과 도착 후(카드, 일기)에 씁니다. 주행 중에는 "로디와 드라이브" 알림이 떠 있고, 알림에서 `그만 달리기`를 누를 수 있습니다.
- 갈림길이 다가오면 음성으로 묻고, 내비 화면 위에 `← 바다 / 시내 →` 버튼이 달린 알림도 함께 띄웁니다. 말로 답해도 되고 알림 버튼을 눌러도 됩니다.
- 도착하면 서비스가 기록을 저장하고 음성으로 한마디를 한 뒤, "도착했어" 알림을 띄웁니다. 앱을 열면 도착 카드가 나옵니다.

### 갈림길 선택
- 코스 중간에 성격이 다른 길로 갈라지는 지점을 미리 찾아 둡니다.
- 갈림길이 다가오면 "곧 갈림길이야. 왼쪽은 바다, 오른쪽은 시내. 어디로 갈래?"라고 묻고 음성 인식으로 대답을 듣습니다. 화면의 큰 버튼으로도 고를 수 있고, 대답이 없으면 원래 길로 갑니다.
- 고른 쪽으로 코스 뒷부분, 음악 장면 목록, 내비 경로를 다시 만듭니다.

### 막힐 때 묻기
- 출발할 땐 괜찮았는데 달리다 점점 막혀서 예정보다 많이 늦어지면(4분 또는 예정 시간의 12% 이상, 시속 20km 아래로 달리는 중) 한 번 묻습니다. "길이 꽤 막히네. 이대로면 5분쯤 늦어. 길을 바꾸면 원래 시간에 맞출 수 있어. 그대로 갈까, 바꿀까?"
- 늦어진 정도는 지금까지 달린 시간과, 같은 거리를 지도 속도로 달렸을 때 걸렸을 시간의 차이로 잽니다.
- `길 바꾸기`는 지금 달리는 도로 조각이 끝나는 지점에서 갈라져 돌아오는 길입니다. 지나온 곳은 다시 지나지 않고, 남은 예상 시간이 원래 예정 시간 안에 드는 길 중 장면이 많이 남는 길(같으면 오래 달리는 길)을 고릅니다. 원래 길보다 3분 넘게 줄지 않으면 묻지 않고 늦어진다고만 말합니다.
- 길을 바꾸면 못 보게 되는 장면을 화면과 알림에 미리 보여 줍니다. 대답은 말, 화면 버튼, 알림 버튼 모두 되고, 대답이 없으면 원래 길로 갑니다.
- 아직 남은 정체가 얼마나 될지는 모르기 때문에, 예상 시간은 남은 길을 지도 속도로 달린다고 보고 계산합니다.

### 드라이브 OST
- 곡이 대기, 순항 A, 순항 B, 빌드업 1, 빌드업 2, 숨 고르기, 드롭, 여운 파트로 나뉘어 있고 스템 6개(pad, bass, arp, lead, drums, fx)가 같은 마디 위치에 놓여 있습니다.
- 마디가 끝날 때마다 현재 속도와 다음 장면까지의 예상 도착 시간을 보고 다음에 틀 마디를 고릅니다.
  - 장면 25초 전부터 빌드업, 터널 출구 장면이면 터널에 들어서는 순간부터 빌드업을 쌓습니다.
  - 숨 고르기 2마디가 끝나는 순간이 도착 시각과 가장 가깝게 맞춰 드롭이 터집니다.
  - 정체로 늦어지면 빌드업 2마디를 반복해서 시간을 늘리고, 다시 속도가 나면 다음 파트로 넘어갑니다.
  - 순항 중에는 속도에 따라 차분한 파트와 리듬이 있는 파트를 오가고, 서 있으면 대기 파트로 갑니다.
- 모든 스템을 한 오디오 스트림에 직접 섞기 때문에 파트를 건너뛰어도 싱크가 어긋나지 않습니다.

### 반려차 로디
- 표정이 있는 캐릭터가 모든 화면에 있습니다. 말할 때 입이 움직이고, 듣는 중, 갈림길, 드롭, 정체 같은 상황마다 표정이 바뀝니다.
- 인사, 코스 안내, 장면 직전 한마디, 정체, 갈림길, 드롭 뒤 한마디, 도착 소감을 음성(TTS)으로 말합니다. 대사는 상황별 템플릿이고, 주행 중에는 짧게, 드롭 순간에는 말하지 않습니다.
- 내비 안내 음성이 나오는 동안은 기다렸다가 말합니다. 말하는 동안 음악 볼륨을 낮춥니다.
- 함께 달린 거리, 횟수, 첫 드라이브 날짜, 지난 드라이브 목록을 기기 안에 저장하고 "로디의 일기" 화면에서 보여 줍니다. 첫 드라이브, 100km 단위 누적, 같은 코스 재방문 때 기념 대사가 붙습니다.

### 도로 테이스팅 노트와 취향 학습
- 도착하면 달린 도로 조각의 굽이, 오르막과 내리막, 터널, 바다 구간, 신호 밀도, 정체 시간으로 "초반 율곡로 해안에서 굽이 4연속, 터널 0.6km 빠져나오자 동해" 같은 노트를 만듭니다.
- 주행 중 속도 기록으로 끊김 없이 흐른 비율(리듬)을 재고, 리듬 있게 달린 코스의 성격과 갈림길에서 직접 고른 길에 점수를 쌓습니다. 이 취향은 다음 코스 점수와 홈 화면의 추천 코스에 반영됩니다.

### 시뮬레이션 주행
- 에뮬레이터는 실제로 달릴 수 없어서, 코스 구간 속도로 가짜 속도와 위치를 만들어 재생합니다(1, 10, 20, 40배속).
- 장면 45초 전과 갈림길 앞에서는 자동으로 1배속으로 느려져 대사와 빌드업을 온전히 들려줍니다.
- 시연용으로 두 번째 장면 바로 앞에 지도에 없는 정체를 한 번 넣습니다. 음악이 빌드업을 반복하며 기다리는 모습을 볼 수 있습니다.
- 갈림길 뒤, 앞뒤로 장면이 없는 곳에는 서서히 막히는 긴 정체(시속 25km로 줄었다가 몇 km를 시속 12km로)를 넣어 "막힐 때 묻기"를 볼 수 있게 합니다. 질문하는 동안은 1배속으로 달립니다. 코스에 그런 자리가 없으면 넣지 않습니다.
- 시뮬레이션을 끄면 실제 차량 속도를 읽습니다.

## 사용한 SDK
- Pleos NaviHelper 3.0.5: 경유지 포함 경로 요청(requestRouteWithWaypoints), 경로 취소
- Pleos TextToSpeech 3.3.1: 반려차 음성(한국어). 안 되면 안드로이드 기본 TTS로 넘어갑니다.
- Pleos SpeechToText 3.3.1: 코스 요청과 갈림길 대답 인식
- 차량 속도: AAOS Car API(`android.car`, `CarPropertyManager`의 PERF_VEHICLE_SPEED)

필요한 권한: `android.car.permission.CAR_SPEED`, `pleos.car.permission.NAVI_ROUTE`, `pleos.car.permission.NAVI_ROUTE_SEARCH`, `pleos.car.permission.TTS_SERVICE`, `pleos.car.permission.STT_SERVICE`, `android.permission.FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `POST_NOTIFICATIONS`(처음 실행할 때 알림 허용 창이 한 번 뜹니다)

## 개발·테스트 환경
- Android Studio Rabbit 2 (2026.2.2)
- Pleos Connect Emulator v2.1.0 (Pleos Connect v2.1.0 APIs, Android 14 / API 34), Cold boot, RAM 4GB
- 화면 규격: 2560 x 1440, density 160 (앱 영역은 오른쪽 약 1680 x 1210)
- Kotlin, minSdk 28, targetSdk 34, compileSdk 37, AGP 9.4.1, Gradle 9.9.1

## 실행 방법
1. Android Studio에서 Pleos Connect v2.1.0 AVD를 만들고, 기본 부팅(Default boot)을 Cold로 설정합니다.
2. 에뮬레이터를 실행합니다. 부팅이 끝나면 아래 둘 중 하나로 설치합니다.
   - 제출용 APK: `adb install apk/DeepTactics_ROADIE_release.apk`
   - 소스에서: 이 저장소를 Android Studio로 열고 Gradle 동기화 후 `app`을 실행합니다.
3. 음성으로 말하려면 에뮬레이터 확장 컨트롤(Extended controls) > Microphone에서 "Virtual microphone uses host audio input"을 켭니다. 마이크 없이도 예시 문장과 화면 버튼으로 모든 흐름을 진행할 수 있습니다.
4. 홈에서 말하거나 예시를 눌러 코스를 만든 뒤 `출발`을 누릅니다. 시뮬레이션 주행은 기본으로 켜져 있고 옆 버튼으로 배속을 바꿉니다.
5. 처음 상태로 시연하려면 기록을 지웁니다: `adb shell pm clear com.deeptactics.roadie`

APK는 `apk/` 폴더에 있습니다: `apk/DeepTactics_ROADIE_release.apk`

## 알아둘 점
- 도로 데이터는 수도권과 강릉만 있습니다. 지점 사이의 경로는 OSRM이 고른 일반 최단 경로라서 "가장 풍경 좋은 길"이 아니고, 장면 판정은 위의 단순한 기준입니다. 전국 확대(서버에서 지역별로 생성), 실제 GPS를 코스 도로에 맞춰 진행률을 정확히 재는 방식, 시야와 노면 같은 판정은 로드맵입니다. 지금 진행률은 속도를 적분해 구하므로 내비가 다른 길로 안내하면 어긋날 수 있습니다.
- 앱이 쓰는 도로 데이터는 미리 계산해서 넣은 것이라, 지도가 바뀌어도 스크립트(`python tools/osm_extract.py`, `python tools/build_roads.py`, 처음엔 지도 파일을 받느라 오래 걸림)를 다시 돌리기 전에는 반영되지 않습니다.
- 말은 키워드 규칙으로 알아듣습니다. 시간, 분위기, 조건 외의 자유로운 대화는 하지 않습니다.
- 에뮬레이터에서 Pleos 음성 인식은 서버 인증이 없어 기기 안 인식으로 넘어가는 것까지 확인했습니다. 실제 인식 결과는 마이크를 연결해서 확인해야 합니다.
- 내비 경로 요청은 에뮬레이터 내비가 응답하는 것까지 확인했습니다. 에뮬레이터 내비의 현재 위치는 성남(수정구 시흥동)으로 고정이라, 내비가 안내하는 실제 거리는 앱의 코스 거리와 다를 수 있습니다.
- 실제 차량 속도 입력은 에뮬레이터에서 값(0 km/h)이 들어오는 것까지 확인했습니다.
- 내비 앱이 화면을 차지하는 동안 우리 화면은 보이지 않습니다. 시연 영상에서 우리 화면을 보이려면 하단 앱 바에서 ROADIE를 눌러 돌아오면 됩니다(주행은 계속됩니다).
- 알림 위의 갈림길 버튼은 에뮬레이터에서 내비 위에 뜨고 눌러서 동작하는 것까지 확인했습니다. 실제 차량의 알림 정책은 확인하지 못했습니다.
- 바다 코스는 40배속으로 처음부터 도착까지 약 5분 걸립니다.

## 폴더 구조
- `app/` 안드로이드 앱 소스
  - `RoadMap.kt` 도로 조각 형식과 지역 파일 읽기, `Composer.kt` 말 해석과 순환 코스 생성, `Course.kt` 코스와 갈림길
  - `Arranger.kt` 파트 재배열 규칙, `Mixer.kt` 스템 믹서, `DriveSource.kt` 시뮬레이션 주행
  - `DriveService.kt` 주행 서비스, `Session.kt` 서비스와 화면이 주고받는 상태, `RoadieApp.kt` 공용 객체(음성, 내비)
  - `Speaker.kt` 음성 출력, `Listener.kt` 음성 인식, `Lines.kt` 대사, `Taste.kt` 테이스팅 노트와 취향
- `app/src/test/` 음악 타이밍, 코스 생성, 정체 질문 테스트
- `assets_src/music/` 음악 스템 원본(wav)
- `app/src/main/assets/roads/` 지역별 도로 데이터(JSON, 자동 생성)
- `tools/osm_extract.py`, `tools/build_roads.py`, `tools/regions/` 지도 데이터에서 지역별 도로 조각 값을 재서 JSON을 만드는 스크립트(인터넷 필요, 파이썬과 pyosmium)
- `tools/make_loops.py` 음악 스템 생성 스크립트 (numpy 필요)
- `apk/` 제출용 release APK

## 음원
앱의 음원은 `tools/make_loops.py`로 합성한 곡이며 외부 음원은 사용하지 않았습니다.
